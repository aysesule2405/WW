# UI Sound Effects

Shared sounds used across the dashboard and all games.

| File       | Duration | Trigger              | Description                                          |
|------------|----------|----------------------|------------------------------------------------------|
| click.mp3  | ~0.1s    | Any button click     | Short soft click — very subtle, not distracting      |
| hover.mp3  | ~0.07s   | Menu item hover      | Even softer high tick — almost subliminal            |

## Sourcing suggestions
- Freesound.org: "ui click", "interface beep"
- Kenney.nl: UI audio pack (free)
- Mixkit.co: "click button"
