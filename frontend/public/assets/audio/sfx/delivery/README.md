# Delivery on the Wind — Sound Effects

All files: MP3, mono or stereo, normalized to -6 dB peak.

| File          | Duration | Trigger                              | Description                                                      |
|---------------|----------|--------------------------------------|------------------------------------------------------------------|
| pickup.mp3    | ~0.4s    | Player steps on a package            | Soft rustle / paper bag scrunch, ends with a small pop           |
| deliver.mp3   | ~0.8s    | Correct delivery to a house          | Warm satisfying chime — two rising tones, short reverb tail      |
| wrong.mp3     | ~0.4s    | Wrong package delivered to house     | Low dull thud or buzzer — communicates "no"                      |
| footstep.mp3  | ~0.15s   | Each tile the player walks on        | Soft grass footstep — quiet, not distracting                     |
| tick.mp3      | ~0.1s    | Every second when < 30s remain       | Short dry click, like a clock tick                               |
| win.mp3       | ~2s      | All 4 deliveries complete            | Triumphant little jingle — ascending chime cascade               |
| lose.mp3      | ~1.5s    | Time runs out                        | Sad descending tones, melancholy short fanfare                   |
| interact.mp3  | ~0.3s    | Inspect package or house             | Light two-note inspection chime                                  |
| talk.mp3      | ~0.4s    | Talk to a nearby NPC                 | Gentle conversational two-note cue                               |
| wind.mp3      | ~0.5s    | Every fourth movement step           | Soft filtered wind whoosh                                        |
