Tile Art Upload Folder
======================
Place your custom tile PNG images here. Suggested filenames:

  grass.png         - Base walkable terrain
  grass_alt.png     - Alternate grass (checkerboard variant)
  path.png          - Dirt/stone path (speeds up movement)
  path_alt.png      - Alternate path tile
  tree.png          - Single tree tile (non-walkable)
  tree_dense.png    - Dense forest tile (non-walkable)
  water.png         - River / lake tile (non-walkable)
  water_alt.png     - Alternate water with different wave pattern
  swamp.png         - Swamp tile (walkable but slow)
  swamp_alt.png     - Alternate swamp
  bridge.png        - Bridge over water (walkable at normal speed)
  ocean.png         - Deep ocean tile (non-walkable)
  ocean_shore.png   - Shore transition tile

Recommended tile size: 48×48 px (matches the game's TILE constant).
Use PNG with transparency where needed (e.g. tree foliage edges).
